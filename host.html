Dernière étape avant de commencer

Connecte le site à une base de données (gratuit, 5 min)

Ce site attribue les groupes en direct et garde tout synchronisé entre toi et tes invités — ça nécessite une base partagée.

  1. Va sur console.firebase.google.com, crée un projet gratuit.
  2. Icône </> "Ajouter une application Web", copie l'objet firebaseConfig.
  3. Colle ses valeurs dans js/firebase-config.js (remplace les "REMPLACE_MOI").
  4. Menu de gauche → "Realtime Database" → "Créer une base de données" → mode test.
  5. Republie/redéploie le site, puis recharge cette page.
